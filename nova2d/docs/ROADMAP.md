# Roadmap Nova2D

**V0.2 – Compilar e testar**: primeiro build do editor Linux e do template Android; rodar o projeto modelo em aparelho; corrigir o que aparecer.
**V0.3 – Editor 2D-only**: esconder nós/menus/docks 3D no editor (começar por `editor/scene/3d`, menu de criação de nós e perfil de recursos do editor); cena inicial sempre 2D.
**V0.4 – Mobile first**: UI do editor com alvos de toque maiores (tema), gestos de pinça/pan no viewport 2D, presets de exportação Android já preenchidos.
**V0.5 – Melhorias de jogo**: mais nós mobile (botões de ação com arrasto, câmera com shake, safe-area automática, haptics), templates de gênero (plataforma, top-down, puzzle).
**V0.6 – Tamanho/desempenho**: `text_server_fb`, remover módulos não usados, medir APK e FPS em aparelhos de entrada.
**V1.0** – Branding completo, ícones, splash, instalador.
